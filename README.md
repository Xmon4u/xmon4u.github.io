# XMON4U — Interactive Audio-Visual Portfolio

Welcome to the official interactive portfolio of **XMON4U**.

**Live:** [https://xmon4u.github.io](https://xmon4u.github.io)

### Features

- 12 synchronized soundtracks with real-time Web Audio API FFT analysis
- 12 unique audio-reactive visualizer themes (Cyber, Neon Rain, Thunderstorm, Sakura, Frost, Solar Fire, and more)
- 12 theme-adaptive XMON4U brand effects
- 12 high-performance dynamic hardware-accelerated cursors
- Zero external dependencies — pure Vanilla WebGL, Canvas2D, and Web Audio

---

*Built with high-precision audio synchronization, custom shaders, and particle physics.*
